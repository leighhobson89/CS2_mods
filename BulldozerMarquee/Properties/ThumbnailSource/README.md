# Thumbnail source

`../Thumbnail.png` is a screenshot of `thumb.html`, so it can be regenerated at
any size rather than re-drawn by hand.

## These SVGs are copies, not the game's icons

The five SVGs here are **derivatives made for this poster only**. The game's real
icon art in `../../icon/` is never edited — recolouring an icon in place to suit a
promo image would change what players see on the buttons. Anything the thumbnail
needs in a different colour gets a copy in this folder instead.

| File here | Copied from | What changed |
|---|---|---|
| `dozer.svg` | `icon/toggle-off.svg` | Only the second path — the machine itself, without its blue plate — refilled with a gold gradient |
| `marquee.svg` | `icon/marquee.svg` | Blue plate to dark asphalt, white glyph to amber |
| `polygonal.svg` | `icon/polygonal.svg` | Same |
| `freeform.svg` | `icon/freeform.svg` | Same |

The consequence is that these do **not** track the game icons. If the button art
is ever redrawn, re-derive these by hand and re-render.

## Rebuilding

From this directory:

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless --disable-gpu `
    --hide-scrollbars --force-device-scale-factor=1 --window-size=512,512 `
    --screenshot="..\Thumbnail.png" thumb.html
```

`--window-size` is the output size, and the CSS is pinned to 512x512 — change both
together if a different size is ever wanted. The skyline is generated by a seeded
PRNG in the page so every render is identical.
